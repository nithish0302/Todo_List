# Todo List

A simple Todo List web application built using HTML, CSS, and JavaScript.

The application allows users to add tasks with a specific date and manage them based on their current status.

## Features

- Add new tasks
- Select a date for each task
- Edit existing tasks
- Complete tasks
- View today's tasks
- View completed tasks
- View tasks that are yet to be completed
- View missed tasks
- Simple and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/nithish0302/Todo_List.git
```

2. Open the project folder.

3. Open `index.html` in a web browser.

4. Start adding and managing your tasks.
